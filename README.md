# FSI · IC Jardim São Judas

Sistema do programa Família Saudável Integral (Cidade Social).

- Site: Nuxt/Vue, publicado pelo GitHub Actions (`.github/workflows/deploy.yml`) a cada envio na branch `main`.
- `public/config.json`: endereço público da API (Apps Script). Não é senha.
- `backend/Codigo.gs`: cópia do backend que roda no Google Sheets (Extensões → Apps Script).
